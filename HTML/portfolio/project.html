🌐 Campus Navigation System

A web-based application designed to help students, visitors and staff easily find different locations within a college campus.

🎯 Project Aim

To develop a user-friendly application that makes campus navigation simple and helps users find their destinations quickly.

💡 Key Features

  • QR Code-Based Access
  • Interactive Campus Map
  • Location Search
  • Starting Point and Destination Selection
  • Route Visualization

🛠️ Technologies Used

Technology Purpose
HTML Website Structure
CSS Website Design
JavaScript Navigation and Functionality
Python QR Code Generation

📌 Project Outcome

The application provides an easy way to locate campus facilities, reduces confusion and saves time for students and visitors.
