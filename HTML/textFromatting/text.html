HTML Text Formatting Tags

H1 - Largest Heading Used for Main Titles

H2 - Second Level Heading Used for Sections

H3 - Third Level Heading Used for Subsections

H4 - Fourth Level Heading

H5 - Fifth Level Heading
H6 - Smallest Heading Used for Minor Titles

P Tag - The paragraph tag is used to define a paragraph of text. It automatically starts content on a new line and adds spacing before and after it.
BR Tag - Used to break the current line and continue content on the next line. It does not create a new paragraph.

B Tag - Displays text in bold style without adding any semantic importance.

STRONG Tag - Indicates that the content is important and usually displays it in bold.
I Tag - Displays text in italic style for visual presentation.
EM Tag - Emphasizes text and usually displays it in italic style.
U Tag - Underlines the text to draw attention to it.
SMALL Tag - Displays text in a smaller font size than normal text.

SUP Tag - Used to display superscript text.

Example:X2+Y2=Z2

SUB Tag - Used to display subscript text.

Example:H2O and CO2
